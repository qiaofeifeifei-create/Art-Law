1.1 行业分类

行业大类归属

ID: 1001 行业分类 国民经济 文化产业

拍卖与艺术咨询在国民经济行业分类（GB/T 4754）中主要属于 R — 文化、体育和娱乐业 门类下的 文化艺术业（大类87）。

层级代码名称
门类R文化、体育和娱乐业
大类87文化艺术业
中类874文物及非物质文化遗产保护
中类889其他文化艺术业（艺术咨询/经纪）
跨类F51批发业（艺术品交易）

行业特征：高净值驱动、信息不对称显著、长周期+高单价、政策敏感

→ 关联：法律法规与合规

艺术市场的双轨结构

ID: 1002 一级市场 二级市场
维度一级市场二级市场
定义艺术家作品的首次销售艺术品的再次流通交易
参与者画廊、艺博会、艺术家本人拍卖行、二手经销商
定价逻辑画廊定价市场竞价
利润率40%~60%10%~20%

中国市场特殊性：一级市场发育不足，拍卖行占主导；"一二级市场倒挂"突出

1.2 一级市场

画廊商业模式

ID: 1003 画廊 代理

画廊是艺术家的"商业代理人"。收入模式分三种：代理销售（画廊50%/艺术家50%）、买断、保底+分成。

艺博会

ID: 1004 艺博会 Art Basel Frieze

全球主要艺博会：Art Basel（巴塞尔/迈阿密/香港/巴黎）、Frieze（伦敦/纽约/洛杉矶/首尔）、TEFAF（马斯特里赫特/纽约）、西岸（上海）、ART021（上海）

一场艺博会4~5天的交易量可占画廊全年营收的30%~60%

艺术家代理与定价

ID: 1005 定价 艺术家

艺术家市场价格五阶段：萌芽期（¥1K~1万）→ 上升期（¥1万~5万）→ 成长期（¥5万~30万）→ 成熟期（¥30万~100万）→ 蓝筹期（¥100万+）

画廊控制年涨价幅度在15%~30%

1.3 二级市场

拍卖行商业模式

ID: 1006 拍卖行 佣金

全球三大拍卖行：佳士得（1766，伦敦，~$65亿）、苏富比（1744，纽约，~$60亿）、富艺斯（1796，伦敦/纽约，~$15亿）

国内头部：中国嘉德（1993）、北京保利（2005）、永乐拍卖、西泠拍卖

买家佣金占拍卖行总收入60%~70%。佣金阶梯：≤50万港币 26% / 50万~1000万 20% / >1000万 14.5%

拍卖会类型与私洽

ID: 1007-1008 春秋拍 私洽

春拍（3~5月）+ 秋拍（10~12月）+ 四季拍 + 网络拍卖 + 专场拍卖

私洽占佳士得/苏富比成交额的20%~30%，是增长最快的业务板块

2.1 拍卖全流程

征集 → 图录 → 预展 → 竞价 → 结算

ID: 2001-2003
  1. 征集：藏家委托（40%）+ 专家开发（30%）+ 品牌吸引（15%）+ 第三方推荐（10%）+ 线上（5%）
  2. 图录：拍品编号/图片/估价/来源/著录/品相报告，印刷+在线
  3. 预展：拍卖前3~7天，买家实物查验
  4. 竞价：现场/电话/书面/线上/缺席五种方式
  5. 结算：买家付款后30~45天向卖家付款
2.2 结算与费用

买家费用与卖家结算

ID: 2004-2005

买家总支付 = 落槌价 + 买家佣金（15%~28%）+ 税费 + 运输/保险

卖家净得 = 落槌价 - 卖家佣金（2%~15%）- 保险费 - 图录费

3.1 中国书画（5条）

品类概述

ID: 3001 书画 山水 花鸟

中国书画占国内拍卖市场成交额的50%~60%，是中国市场绝对主力。

分类：山水/花鸟/人物（题材）；工笔/写意/没骨（技法）；立轴/手卷/册页/扇面（装裱）；古代/近现代/当代（时代）

古代书画

ID: 3002 宋元 明清

宋元：范宽、赵孟頫、倪瓒 — 精品¥5000万~数亿

明四家：沈周、文徵明、仇英、董其昌 — ¥500万~1亿

四僧：八大山人、石涛、弘仁、髡残 — ¥1000万~2亿

四王：王时敏、王鉴、王翚、王原祁 — ¥100万~3000万

近现代书画

ID: 3003 张大千 齐白石

第一梯队（¥5000万~3亿）：张大千、齐白石、傅抱石、徐悲鸿、李可染

第二梯队（¥1000万~1亿）：黄宾虹、潘天寿、吴昌硕、林风眠

第三梯队（¥200万~3000万）：吴冠中、李苦禅、黄胄

中国书法

ID: 3004
王羲之《快雪时晴帖》（唐摹本）— 台北故宫博物院藏

书法市场通常比绘画市场低3~5倍，顶级作品可达千万级（曾巩《局事帖》2.07亿元）。

"书法是最后的洼地"是行业内常见论点

当代水墨与实验水墨

ID: 3005 当代水墨
徐冰《天书》— 装置艺术，将水墨推向文化符号层面

徐冰、谷文达（¥50万~500万），新工笔（徐华翎、张见，¥10万~200万）

3.2 现当代艺术（5条）

现当代艺术市场总览

ID: 3010

现当代艺术占全球拍卖成交额45%~50%，价格天花板最高。

现代艺术（1880s~1960s）→ 战后艺术（1945~1970）→ 当代艺术（1970s~至今）

西方现代艺术大师

ID: 3011

S-tier（$8000万~$4.5亿）：毕加索、莫奈、梵高、达芬奇

A-tier（$3000万~$1.5亿）：沃霍尔、马蒂斯、罗斯科

毕加索全球拍卖总成交额最高的艺术家

战后与当代艺术

ID: 3012
安迪·沃霍尔《金宝汤罐头》— 波普艺术标志性作品

年轻一代（1990s后）市场热度高但泡沫争议较大

亚洲现当代艺术

ID: 3013
草间弥生《无限镜屋》— 沉浸式装置，标志性波点风格

日本：草间弥生、奈良美智、村上隆。韩国：金焕基、李禹焕。中国：赵无极（最高¥2.5亿）、朱德群

中国当代艺术代际：玩世/政治波普（'85新潮）→ F4+1（曾梵志、刘野等）→ 70/80后 → 90后

版画与限量作品

ID: 3014
村上隆《太阳花》版画系列

版画是入门高端艺术的最佳通道。签名版价格翻2~5倍。

类型：丝网印刷（沃霍尔，$5000~$50万）、蚀刻（毕加索，$1000~$5万）、石版画、木刻

4.1 鉴定方法论

传统鉴定（眼学）四维

ID: 4001

笔墨/笔触 → 款识/签名 → 材质 → 风格

眼学局限性：严重依赖专家经验、主观性强、造假技术演进、团伙作案

科技鉴定方法

ID: 4002
技术适用特点
碳-14测年纸/绢/木/骨精度±50年
X射线荧光（XRF）颜料/金属/陶瓷釉面无损、快速
红外反射成像素描底层/签名修改发现底层构图
热释光测年（TL）陶器/瓷器需取样
拉曼光谱颜料/矿物成分无损、高特异

现代鉴定 = 眼学（60%~70%）+ 科技（20%~30%）+ 来源考证（10%~20%）

鉴定争议与法律后果

ID: 4003

拍卖后发现赝品 → 买家可主张撤销合同（《拍卖法》第61条）。拍卖行声明不保真情况下责任有限（故意隐瞒除外）

4.3 Provenance（来源）

来源定义与价值

ID: 4020

Provenance 指艺术品的完整拥有/展示/出版历史记录。著名藏家递藏可带来 20%~50% 的溢价。

来源调查与品类鉴定对照

ID: 4021-4030

工具：Artprice、Artnet、Getty Provenance Index、Chinese Painting Database

风险等级：中国书画 ⭐⭐⭐⭐⭐ 极高，瓷器 ⭐⭐⭐⭐ 高，珠宝 ⭐⭐ 中低

⚖️ 法律法规与合规

条目
5.1 国内核心法律

《中华人民共和国拍卖法》

ID: 5001

第61条（最关键条款）：拍卖人未声明不保真的，对买受人承担瑕疵担保责任；声明不保真的，不承担瑕疵担保责任（故意隐瞒除外）

实践中买家打赢官司的案例极少（需证明拍卖行"故意隐瞒"）

《文物保护法》

ID: 5002

禁止买卖：国有文物、非国有馆藏珍贵文物、出土文物、来源不合法文物

文物拍卖须取得文物拍卖许可证，标的逐件报送省文物局审核

《艺术品经营管理办法》（文化部令第56号）

ID: 5003

经营备案 + 尽职调查（来源登记义务）+ 真实性责任 + 消费者7日退货权

5.2 国际公约

UNESCO 1970 & UNIDROIT 1995

ID: 5020-5021

UNESCO 1970：禁止非法进出口文化财产。中国已加入，但不溯及既往。

UNIDROIT 1995：被盗物必须归还，善意买受人可获合理补偿。中国尚未加入。

5.3 跨境与纠纷

艺术品进出口实务 & 真伪纠纷

ID: 5030-5041

进口税费：关税6%~12% + 增值税13% + 消费税0%

CITES公约：象牙、犀角、虎骨、檀香紫檀等受管制

香港优势：零关税、零增值税 → 全球艺术品交易中心

反洗钱合规

ID: 5050

艺术品交易反洗钱义务：客户尽职调查（CDD）+ 大额交易报告 + 可疑交易报告 + 记录保存≥5年 + KYC

艺术基金模式

Art Loan

ID: 6010

6.3 保险

艺术品保险

ID: 6020-6021

6.4 税务与捐赠

捐赠与税务筹划

ID: 6030-6031

自由港（日内瓦/卢森堡/新加坡/上海）：艺术品存放可延期缴税，在港内交易无需缴纳进口关税和增值税

艺术信托

ID: 6040

功能：资产隔离、税务规划、传承控制、多代继承、专业管理。建议资产¥500万+考虑
